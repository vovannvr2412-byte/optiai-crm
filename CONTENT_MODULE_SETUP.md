# Установка Контент-завода

CRM принимает готовую статическую веб-сборку и устанавливает её без изменения кода или повторного деплоя Vercel.

## Подготовка Supabase

Выполните миграцию `supabase/migrations/0013_content_module_installer.sql` в Supabase SQL Editor. Она создаёт реестр установленного модуля и приватный bucket `content-modules`.

## Поддерживаемый пакет

- ZIP-архив, папка или набор готовых файлов;
- обязательный файл `index.html`;
- HTML, CSS, JavaScript, изображения, шрифты, документы и медиа;
- не больше 20 МБ в ZIP, 40 МБ после распаковки и 250 файлов.

Если передаются исходники React или Next.js, сначала выполните статическую сборку. Для Next.js результатом должен быть каталог `out`, для Vite обычно используется `dist`.

Опциональный файл `content-module.json` в корне пакета:

```json
{
  "name": "Контент-завод",
  "version": "1.0.0",
  "entry": "index.html"
}
```

Без манифеста CRM автоматически находит ближайший `index.html` и использует стандартное название.

## Установка

1. Войдите как руководитель.
2. Откройте приложение `Контент`.
3. Нажмите `Архив или файлы` либо `Выбрать папку`.
4. Дождитесь проверки и установки.

Новая версия заменяет предыдущую только после успешной загрузки всех файлов. Сотрудники с доступом к приложению `Контент` сразу увидят установленный модуль. Загруженный JavaScript запускается в изолированном iframe без доступа к сессии CRM, камере, микрофону и геолокации.
